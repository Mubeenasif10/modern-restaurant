

# Maison Table – Modern Restaurant Website

A modern, elegant, and fully responsive restaurant website built with React and CSS.

## 🌐 Live Demo

[https://maison-table.netlify.app/](https://maison-table.netlify.app/)

## ✨ Features

- Modern and elegant restaurant design

- Responsive navigation bar

- Mobile-friendly navigation menu

- Attractive hero section

- Restaurant about section

- Interactive food menu with category filters

- Table reservation form with success message

- Food gallery

- Customer reviews section

- Contact information

- Responsive footer

- Mobile, tablet, and desktop support

## 🛠️ Technologies Used

- React.js

- JavaScript

- CSS3

- HTML5

- Vite

## 🚀 Run Locally

1. Clone the repository:

   ```bash

   git clone [https://github.com/Mubeenasif10/modern-restaurant.git](https://github.com/Mubeenasif10/modern-restaurant.git)

   ```

2. Open the project folder:

   ```bash

   cd modern-restaurant

   ```

3. Install dependencies:

   ```bash

   npm install

   ```

4. Start the development server:

   ```bash

   npm run dev

   ```

5. Open the local URL shown in your terminal.

## 📦 Production Build

```bash

npm run build

```
